# 송전 전압에 따른 손실 비교 계산기

지기 프로젝트 (학급 특색활동) ·

## 탐구 질문
같은 전력을 보낼 때, 송전 전압과 전선의 저항에 따라 전력 손실은 얼마나 달라질까?

## 계산 방법
- 전류 I = 송전 전력 P ÷ 송전 전압 V
- 손실 전력 = I² × 전선 저항 R
- 손실률 = (손실 전력 ÷ 송전 전력) × 100

전선 저항에 의한 손실만 다루는 단순화된 모형이다.
